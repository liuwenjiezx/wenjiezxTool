# wenjiezxTool — 个人 ComfyUI 功能工具箱（中文友好）

> ComfyUI 自定义节点插件 · 全中文参数 · 共 15 个节点
> 适配 Qwen-Image-2.1 与 KREA2 Turbo 文生图片编辑二合一工作流 · Windows 版 ComfyUI（Python 3.12 / 3.13）

## 功能亮点

- 🚀 **残差缓存加速器（WJZ_TeaCache）**：跳过冗余计算步，提速 30%~60%，质量无损
- 🎛️ **文生图/编辑·画布三合一（WJZ_ModeLatentCanvas）**：模式 + 提示词 + 画面比例 + 图片大小一站式控制
- ✏️ **Krea2 编辑三件套**：源图注入 / 接地指令编码 / 负面提示词强化（跑 KREA2 编辑不用装任何第三方插件）
- ⚡ **SAGE 注意力加速（WJZ_SageAttentionPatch）**：长序列（大图/视频）更快更省显存
- 💬 **全中文参数**：不用记英文

## 安装

下载后把 `wenjiezxTool` 文件夹放进 `ComfyUI\custom_nodes\`，重启 ComfyUI，节点搜索框输入 `wenjiezx` 即可。卸载：删除整个文件夹。

## 工作流

### Qwen-Image-2.1文生图片编辑二合一.json

拖入 ComfyUI 即可使用：

- 单 KSampler + If/Else 开关，一次只采样一个分支，省显存
- 三合一节点控制：模式 / 提示词 / 画面比例 / 图片大小 / 编辑分辨率
- 图片编辑：第 1 张参考图 = 要改的图，第 2 张 = 素材图
- 参考图大小不影响速度，编码节点会自动缩放

### KREA2Turbo文生图片编辑二合一.json

KREA2 Turbo 速版的文生图 / 图片编辑二合一（同样只装本插件就够）：

- 双 KSampler 各用各的参数（文生图 8 步 beta + 负面强化；编辑 10 步 simple + identity_edit LoRA + 接地指令编码），采样完在 LATENT 上二选一
- If/Else 开关惰性求值，**没选中的分支完全不执行**，不浪费算力
- 三合一节点控制：模式 / 提示词 / 画面比例 / 图片大小 / 张数；两个模式的出图大小都跟画布走
- **图片编辑：参考图直接拖进三合一节点下方的图片区**（不用加「加载图像」），「模式图片开关」按顺序分图 —— 第 1 张 = 要改的图/场景，第 2 张 = 素材/主体（Krea2 模型最多吃 2 张）
- 两条支路各带一个**残差缓存加速器**，想关掉就 Ctrl+B 停用它（或把「复用阈值」设 0）
