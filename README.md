## 功能亮点

- 🚀 **残差缓存加速器（WJZ_TeaCache）**：去噪采样时跳过冗余计算步，提速 30%~60%，质量无损（原理同 TeaCache / EasyCache，对照官方源码自研实现）
- 🎛️ **文生图/编辑·画布三合一（WJZ_ModeLatentCanvas）**：模式 + 提示词 + 画面比例 + 图片大小一站式控制，人话下拉，小白友好
- 💬 **全中文参数**：所有节点参数、按钮、说明均为中文，不用记英文
- 🔒 **闭源保护**：节点以编译后的 `.pyd` 分发，看不到 Python 源码

## 安装

1. 下载本仓库，把 `wenjiezxTool` 文件夹放入 ComfyUI 插件目录：

```
ComfyUI\custom_nodes\wenjiezxTool\
    ├── nodes_cp312.pyd   # Python 3.12 版（自动选择）
    ├── nodes_cp313.pyd   # Python 3.13 版（自动选择）
    ├── __init__.py       # 入口（按 Python 版本自动加载对应文件）
    └── web\
```

> 插件会自动识别你的 ComfyUI 内置 Python 版本（3.12 或 3.13），无需手动选择文件。最新版 Windows 便携版（Python 3.13）与旧版（Python 3.12）均可直接使用。

1. 重启 ComfyUI（或刷新浏览器）
2. 节点搜索框输入 `wenjiezx` 即可找到全部节点

卸载：删除整个文件夹即可。

## 配合 Qwen-Image-2.1 二合一工作流

- 工作流结构：单 KSampler + 三个 If/Else 开关（惰性求值，一次只采样一个分支，省显存）
- 三合一节点控制：模式 / 提示词 / 画面比例 / 图片大小 / 编辑分辨率
- 图片编辑：第 1 张参考图 = 要改的图，第 2 张 = 素材图

## 使用建议

- 加速器：1024 图用默认参数（阈值 0.1 / 起始 0.15 / 结束 0.95）即可，跳过率 40%~52%
- 2K 高负载任务偶尔可能触发显卡驱动保护（表现为前端"重新连接"），重启服务即可；频繁出现可改选「超清 约1440」
- 参考图大小不影响速度：编码节点会自动缩放
