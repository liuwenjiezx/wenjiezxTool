## 安装

下载后把 `wenjiezxTool` 文件夹放进 `ComfyUI\custom_nodes\`，重启 ComfyUI，节点搜索框输入 `wenjiezx` 即可。卸载：删除整个文件夹。

## 工作流

仓库内附带 **Qwen-Image-2.1文生图片编辑二合一.json**，拖入 ComfyUI 即可使用：

- 单 KSampler + If/Else 开关，一次只采样一个分支，省显存
- 三合一节点控制：模式 / 提示词 / 画面比例 / 图片大小 / 编辑分辨率
- 图片编辑：第 1 张参考图 = 要改的图，第 2 张 = 素材图
- 参考图大小不影响速度，编码节点会自动缩放
