# wenjiezxTool

ComfyUI 自定义节点插件，全中文参数，共 15 个节点。
适配 Qwen-Image-2.1 文生图片编辑二合一工作流，Windows 版 ComfyUI（Python 3.12 / 3.13）。

## 安装

把 `wenjiezxTool` 文件夹放进 `ComfyUI\custom_nodes\`，重启 ComfyUI，搜索 `wenjiezx` 即可。

## 节点

随机种子生成器、提示词拼接器、多行文本拆分器、时间戳文件名生成器、图片基本信息查看器、数值列表生成器、张量形状查看器、模式选择器、模式文本切换器、文生图/编辑·画布三合一、残差缓存加速器、Krea2 编辑·源图注入、Krea2 编辑·接地指令编码、Krea2 负面提示词强化、SAGE 注意力加速。

## 工作流

仓库内附带 **Qwen-Image-2.1文生图片编辑二合一.json**，拖入 ComfyUI 即可使用。
